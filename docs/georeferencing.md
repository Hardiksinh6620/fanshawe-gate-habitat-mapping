# Georeferencing evidence checklist

PDF pages 6-7 describe image selection, reference data, control points, a polynomial transformation, and an alignment check. The available narrative does not provide a recoverable set of control-point coordinates or full processing settings.

For a later reproduction, record the image date, pixel dimensions, reference-layer provenance, coordinate system, control-point identifiers, transformation choice, and reported residuals. Preserve the distinction between points used to fit a transformation and separate evidence used to check its accuracy.

Inspect the spread of control points and whether features align throughout the study area. A good-looking overlay alone should not be promoted to a quantified accuracy result. This checklist does not claim that a new georeferencing run has been completed.
