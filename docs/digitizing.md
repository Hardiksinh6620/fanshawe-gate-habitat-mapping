# Digitizing and classification checks

The report describes tracing habitat boundaries and classifying the site, with the habitat figure on PDF page 11. Recover the original classification codes and the evidence for each boundary before translating the map into a new dataset.

Record the observation scale, snapping choices, multipart features, and treatment of gaps and overlaps. Review neighbouring boundaries together. Keep uncertain labels explicit rather than assigning an unsupported habitat class to complete a map.

An attribute table should link each feature to a stable identifier and its classification evidence. An area total can be arithmetically correct while the underlying polygons overlap. Geometry validation and ecological interpretation are separate checks, neither of which is performed by this repository's simple example.
