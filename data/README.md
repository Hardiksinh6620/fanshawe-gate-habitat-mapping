# Synthetic feature records

These three invented records are only an educational fixture. They do not describe Fanshawe Gate Farm. Each record has a unique feature identifier, a nonempty category, and a positive finite area in square metres.

For real records, also preserve source geometry, survey date, classification scheme, observer or source, and uncertainty. The example does not contain geometry and therefore cannot detect overlapping polygons, gaps, or incorrect area calculations. A valid record format does not establish a valid habitat map.
